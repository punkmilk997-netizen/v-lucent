# Noctelle avatar assets (Sol → Noctelle)

Noctelle replaces Sol as the product identity. Avatar art from the Sol handoff is kept as **Noctelle-named** bundled media. The Sol PowerShell desktop runtime is **not** used or reinstalled.

## Bundled paths (`local-companion/public`)

| Asset | Path | Role |
|-------|------|------|
| Active (primary) | `media/noctelle/noctelle-active.png` | Full-size awake sprite (from `sol-active-v2.png`) |
| Active (alt) | `media/noctelle/noctelle-active-alt.png` | Earlier awake art (from `sol-active.png`) |
| Nap frames | `media/noctelle/noctelle-nap-0.png` … `nap-4.png` | Chibi nap cycle |
| Source sheet | `media/noctelle/noctelle-sprite-sheet.png` | Artist source sheet |
| Manifest | `media/noctelle/manifest.json` | Machine-readable defaults |
| **Noctelle VRM (default)** | `models/noctelle.vrm` | Sol-PNG billboard on VRM humanoid (approx) |
| Legacy VRM | `models/model1.vrm` | Previous default 3D avatar |
| Live2D-style | `models/aka.inx`, `models/Midori.inx` | PuppetRenderer models |

## Default open experience

App defaults to **VRM mode** with `models/noctelle.vrm` (Sol-derived Noctelle). Settings → Avatar can still switch to **Noctelle sprite (2D)** using the PNGs, or load a custom VRM into `%APPDATA%/<app>/custom_vrms`.

## Quality limits (`noctelle.vrm`)

Sol handoff had **PNG sprites only** (no artist VRM). This PC has Blender 5.2 + VRM addon, but **no NVIDIA/torch** for AI image-to-3D.

`noctelle.vrm` is generated by `tools/vrm-build/build_noctelle_vrm.py`:

- VRM 1.0 humanoid armature (`icyp.make_basic_armature`)
- Vertical plane textured with `noctelle-active.png` (alpha blend)
- Tiny stub spheres on limbs for humanoid completeness

It is a **usable paper-doll / billboard** stand-in, not a sculpted character. For a true 3D Sol: commission, VRoid rebuild, or GPU mesh-from-image then retopo/rig.

## Rebuild

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --python tools\vrm-build\build_noctelle_vrm.py
```

Requires the VRM Add-on zip at `tools/vrm-build/vrm_addon.zip` (not committed; download from saturday06/VRM-Addon-for-Blender releases).

## What was not carried over

- No Sol `.ps1` / `.cmd` runtime
- No Sol AppData notes/doodles trial content
- No full 3D mesh-from-PNG (GPU AI unavailable on this machine)
